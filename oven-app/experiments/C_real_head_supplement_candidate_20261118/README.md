## 训练与验证

仍从指定C_real_20261105父权重开始，不在第一候选上接着训练。SHA-256见base_provenance.json。固定24轮、seed42、CPU4线程、最后线性层微调、冻结骨干和BN、类别加权CE+0.5KL、温度2，学习率0.0003，无随机增强；与第一候选训练设置相同。

只保留整鸡未训练输出行不变，不承诺整鸡概率或准确率不变。用比较结果选轮次或调参的流程没有执行。包内关于GPU10轮和其他几何增强权重的文字是另一流程的说明，本次没有据此更换基线或方法。

完整重载三模型预测167张，原模型和第一候选在原143张上分别复现122和127正确。训练期间核对冻结张量、整鸡输出行不变；8张缓存特征与完整通路输出一致。ONNX导出同张量最大logit误差约5.28e-6，通过1e-4容差；未部署或完成该候选浏览器实图评测。
