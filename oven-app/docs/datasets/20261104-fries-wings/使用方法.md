# 本地数据使用方法

我把这次修正保存为独立的本地整理版，原始压缩包继续保留。GitHub中只提供说明和清单，克隆仓库不会得到图片；需要使用图片的组员通过小组约定方式取得整理版。

1. 图片和JSON放在同一个目录，使用相同主文件名，例如chips_a_high_have_0001.png和chips_a_high_have_0001.json。
2. 使用manifest.csv中的image_file在本地目录定位图片。food_class为fries或chicken_wings，对应薯条和鸡翅。
3. 使用SHA-256验证图片与清单一致。更名不改变图片内容，哈希也不改变。旧文件名通过name_changes.csv对应到新文件名。
4. 使用本次整理版JSON的review字段读取人工复核状态；camera_context保留的是采集时的记录，不应把其中旧的false当作本次复核未完成。
5. 先确定数据用于训练、验证还是独立测试，再按同一食材实物、采集会话和连拍来源分组划分。同一来源的相近帧不要分散到不同集合，不能只按文件名随机分图。
6. 确定测试集后固定清单，避免一边调模型一边反复查看测试成绩。

文件名前缀只是命名分组，不足以单独证明光照、食材数量或锡纸等条件已准确标注。整理名称后仍应由采集人向组员解释命名含义。
