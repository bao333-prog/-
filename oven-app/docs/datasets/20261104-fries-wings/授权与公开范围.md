# 授权沟通与公开范围

我在学校／企业提供的设备中采集了这批食材图片。针对上传GitHub的问题，老师向企业方面询问：

> 张总，我们学生自己采集的数据是否可以上传github，咱们公司对于此类数据隐私是否有要求

收到的回复为：

> 这个倒没什么限制，不过github本身可能并不支持这样的使用方式，可能有被封号的风险

我将这段沟通作为本批学生自采食材数据的公开限制说明，隐去与内容无关的群聊账号。原始沟通记录另行保留。该回复没有为其他企业资料、固件或内部文档提供公开许可，也没有指定数据的开源许可证。

我已完成人工检查，确认本批图片没有隐私泄露。此次GitHub只提交数据说明、文件清单、统计、质检、更名对照、使用方法和个人工作日志；原始照片、采集JSON、设备参数及聊天截图均不上传。

企业对数据隐私的答复和GitHub平台存储规则是两件事。当前采用文档和清单方式记录成果，不将约466MiB的原始压缩包提交Git历史。本批数据未在此次提交中对外提供下载，也没有附加未经确认的CC或其他开放数据许可证。
