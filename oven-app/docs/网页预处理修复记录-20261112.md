# 网页图片预处理修复（2026-11-12）

现象：相同权重、相同原图，网页默认 Canvas 缩图可能改变最高候选。确认存在缩小抗混叠差异，以及居中补白使用 floor 而 Pillow 使用 half-to-even 舍入的差异。

修复：以原始分辨率解码到 Canvas 后读取 RGBA，自行执行白底 alpha 合成、带缩小抗混叠的双线性重采样、8位中间结果取整和 Python 式 letterbox 居中，再生成 RGB/NCHW 归一化张量。不再依赖浏览器默认缩图算法或 imageSmoothingQuality 支持。摄像头生成中间 JPEG 时显式启用高质量缩图；它仍有最长边1280与JPEG编码，与上传原图的路径并非完全相同。

模型权重、类别和置信度阈值均未改变。现有文件上传、摄像头控制和取消逻辑保持原样。

验证：
- 8组确定性 RGBA 图案的完整输出张量 SHA256 与项目 Python/Pillow 参考逐字节相同，另有1项奇数补白位置测试。
- 原模型、摄像头测试16项与新预处理测试9项，共25项通过。
- 15张现有原图真实浏览器复测：默认缩图与Python最高候选一致12/15，修复后15/15。
- 此处是一致性抽查，含重复图片，不是独立准确率测试。不能据此宣称模型准确率100%。
- 浏览器解码、色彩管理、EXIF等仍可能与Pillow有差异。本批修复后输入张量的最大单图平均绝对差约 0.00020973191210781015。
