# 本地启动与复现

## 已验证环境

Windows、Python 3.12，具体依赖见 requirements-validated.txt。虚拟环境不提交。

在 oven-app 目录运行：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-validated.txt
.venv/Scripts/python.exe -m pip install --no-deps -e .
.venv/Scripts/python.exe -m backend.app
```

浏览器打开 http://127.0.0.1:8000 ，不要直接双击 HTML。
本机模型已放置在 models/model_C_v2.pt。GitHub 不包含权重；新电脑从已授权模型包取得该文件，或设置 OVEN_MODEL 为模型路径。教师只用于复现训练。
OVEN_PORT 可以修改端口。服务默认只监听本机，用于课程开发演示。

API：GET /api/classes 返回权重类别；POST /api/predict 接收 multipart 的 image 字段。
上传图片只在内存处理，限制10MB、两千万像素。候选置信度低于0.8提示不确定，此阈值仅为交互提示，未校准，不能视为未知类别检测。
无论分数高低均须人工选择；“以上都不是”和“不确定”不会生成烹饪设置。

## 迁移复现路径

原始 records 不修改，不发布含本机路径的清单。创建 JSON 路径映射，例如：

```json
{
  "C:/原机器/项目/runs": "D:/项目/runs",
  "C:/原机器/图片": "D:/食材图片"
}
```

```powershell
python reproduce/relocate.py --source records --destination outputs/relocated --path-map path-map.json
$env:OVEN_RUN_DIR = (Resolve-Path outputs/relocated).Path
python reproduce/run_training.py
```

映射同时作用于 JSON 值、JSON 路径键和 CSV 字段。实际映射前缀需要对应你的原始记录。映射后应复核 train_config.json 的 manifest、data_root、output_dir、checkpoint，以及 data_audit.json 的父模型、对照目录、保护模型路径。CSV 图片路径也须存在。
字体使用 OVEN_FONT；项目根目录使用 OVEN_PROJECT_ROOT；交付目录使用 OVEN_DELIVERY_DIR。

完整重训仍需原包未包含的图片、原C对照权重及 review_and_split.json 等记录。缺少这些不能声称训练复现通过；本次验证的是推理与接口。
