# 模型接入与版本说明

## 本次交付

浏览器发布版使用 C_real_20261105（十四类实拍适配版），来源为小组提供的 `model_C_real.pt`。没有训练或修改权重。

- 原始 PyTorch SHA256：`d66f52f1d26d75364751f913c5e76d1002d71f1742aa10cb2e9ad02528d4548c`
- 发布 ONNX SHA256：`8243f22c65720ffb14ac0350d5d4985997529d956696386ef06de00fa3305be3`
- 随机同张量 PyTorch/ONNX 输出比较通过（rtol=1e-4，atol=1e-4），最大 logit 误差约 4.82e-6。
- 此结果验证导出数值一致性，不代表浏览器/Pillow 图像缩放完全一致，也不是独立测试准确率。
- 原包说明明确没有独立实拍测试成绩。网站不宣称该模型已达到课程精度指标。

## 配置和模型必须一起更新

`docs/model.json` 的 schema_version=1，声明 name、id、version、file、sha256、classes、size、mean、std、resize_mode、color、layout、input_name、output_name、output_type 和 threshold。

类别顺序必须来自权重，不能根据界面重新排序。当前仅支持单图分类、RGB、NCHW、白底 letterbox；YOLO 或其他预处理不能直接套用。模型输出维度和有限数值会在运行时检查；threshold 仅用于显示人工确认提示，不能可靠检测未知类。

模型使用懒加载；首次上传时才加载 ONNX。请求带模型文件指纹，防止同名新权重沿用浏览器缓存。模型配置和加载失败后可以重试；无法中断的 WASM 计算会串行执行并丢弃过期结果。

## 导出新版本

安装项目推理依赖及 onnx、onnxruntime。在仓库根目录将 oven-app/src 加入 PYTHONPATH 后执行：

```powershell
$env:PYTHONPATH = (Resolve-Path oven-app/src).Path
python oven-app/reproduce/export_web.py --model "你的权重.pt" --output "临时导出目录" --id C_real --name "十四类实拍适配版" --version C_real_20261105
```

先查看导出校验结果，再将导出的 model.onnx 和 model.json 一起复制到 docs。先在本地测试，再提交至个人分支并由小组审核合并。

回退时将上一版匹配的 model.onnx 和 model.json 一起恢复；Git 历史保留了原 C_v2 版本。不要只改显示版本名称。

## 修改网页

修改 oven-app/frontend 下源码，然后运行：

```powershell
python oven-app/reproduce/build_pages.py
```

该步骤生成 docs 的发布文件，不覆盖模型及配置。双击仓库根目录 start-local.cmd，在 http://127.0.0.1:4173/ 验证（该启动文件是本机辅助文件，未提交）。

## Python 后端

浏览器版和 Python 后端各自加载权重。后端通过 OVEN_MODEL 指定模型；页面显示实际加载的文件名，避免硬编码成 C_v2。本机已复制 model_C_real.pt 到 oven-app/models，该目录权重按现有 gitignore 不提交，其他电脑需自行取得授权原包。

```powershell
cd oven-app
$env:OVEN_MODEL = (Resolve-Path models/model_C_real.pt).Path
python -m backend.app
```
