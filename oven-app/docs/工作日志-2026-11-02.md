# 2026-11-02 工作日志：接通模型和网页

记录人：@MascoTxTs

今天我主要推进模型和网页的连接，并根据使用中发现的问题调整识别流程。代码实现和自动化测试由 Codex 协助完成。

## 模型与网页连接

原来的网页只能预览图片、手动选择食材。我希望上传图片后能够直接看到模型的识别结果，所以这次接通了图片上传、后端预测和网页显示。

- 用 Flask 接收图片，启动时加载十四类模型，返回前三个候选食材和预测置信度。
- 网页食材列表从模型权重读取，避免列表与模型不一致，也补上了香肠。
- 我要求保留“不确定，需要人工确认”和“以上都不是”，防止识别结果被直接当成正确答案。
- 图片在内存中处理，增加格式、大小和像素数量检查，以及超时、错误提示和更换图片后的旧请求处理。

## 连续识别和按钮调整

使用时我发现，识别后没有明显的入口继续识别下一张。因此增加了“识别下一张”按钮，点击后清空图片、预测结果和确认信息，回到上传状态。

之后我觉得这个按钮太小，又把它调整为与“确认食材信息”一样大的整行按钮，并增加了间距。

对应提交：[e80a4aa](https://github.com/bao333-prog/-/commit/e80a4aa)、[2397194](https://github.com/bao333-prog/-/commit/2397194)。

## 项目整理和评测

我要求把项目整理为 frontend、backend、src、tests、reproduce、docs 等目录，记录实际验证过的依赖版本，并配置 .gitignore。复现脚本增加了路径配置和 JSON/CSV 路径迁移工具。

评测部分增加了旧类、新类宏平均准确率。根据已有验证记录重算，旧类为98.00%，新类为94.5833%。父模型B还缺逐类结果，旧类宏平均下降暂时不能补齐。这些数字是历史验证结果，不是新的独立测试成绩。
