# lichenyi-home：模型接入与版本展示开发记录

日期：2026-11-05。开发方式：使用 Codex 辅助实现，提交记录保存在 feature/lichenyi-home-workspace。

## 工作范围
- 为浏览器分类模型建立显式配置约定，校验类别、预处理、输入输出及数值。
- 加入模型名称、版本、支持类别、加载状态、前三候选置信度和实际耗时展示。
- 支持配置读取及模型识别失败重试；取消、更换和清空时丢弃旧结果。
- 使用模型指纹区分同名文件缓存；实际测试曾发现旧权重缓存，修复后新旧模型输出不同。
- 将小组提供的实拍适配 PT 权重导出为 ONNX，沿用原权重类别和归一化配置，没有重新训练。
- 后端返回实际加载版本及纯推理时间，前端同时兼容浏览器与本机服务两种运行方式。

## 验证记录
- Node 自动测试 6 项通过：配置异常、输出维度与数值、稳定 softmax、加载失败重试、取消旧结果、推理串行执行和缓存版本参数。
- Python 接口测试 4 项通过；以原 C_v2 和实拍适配权重分别运行过。新测试断言版本返回一致、推理耗时非负。
- 真实浏览器：图片上传、原/新模型实际运行、低置信度提示、未知食材人工确认、识别下一张清空、非图片格式校验。
- 导出张量一致性：最大 logit 差约 4.82e-6；发布文件 SHA256 与配置一致。
- 浏览器测试样例为仓库芦笋_10.jpg；实拍适配模型将其最高候选判为西兰花（约53.1%），正确进入不确定提示。此记录仅验证功能，不能用来证明分类准确率达标。
- 未对整套测试集重新评测，也未测试 RK3506；电脑/浏览器耗时不能当作板卡性能。
