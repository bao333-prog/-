## 权重与输入

- 用户提供的原始权重：`oven-app/models/model_C_real_head_candidate.pt`，已随此版本提交，下载完整仓库可运行本地后端。
- 原始权重 SHA256：`0a179bd77d373fb86005517a03befbe0cce93f2d9b435178593eedd62cf7a707`。
- 网页 ONNX SHA256：`389471e33ee12d416250774c97ee9693acdddb8f9398ca4432d1bbacf50febd9`。
- 网络 MobileNetV3-Small，输入 `[1,3,224,224]`，RGB/NCHW；按比例双线性缩图、白底居中补白，ImageNet mean/std；输出 14 类 logits 后计算 softmax。
- 类别严格沿用权重中的顺序：南瓜、吐司、牛排、玉米、西兰花、鸡翅、芦笋、培根、三文鱼、整鸡、土豆、香肠、薯条、可颂。

## 复现与切换

在仓库根目录、已安装项目依赖并设置 `PYTHONPATH=oven-app;oven-app/src` 的环境运行：

```powershell
python oven-app/reproduce/export_web.py --model oven-app/models/model_C_real_head_candidate.pt --output docs --id C_real_head_candidate --name "十四类实拍分类头候选版" --version C_real_head_candidate_20261118
python oven-app/reproduce/verify_web_export.py --model oven-app/models/model_C_real_head_candidate.pt --web-dir docs --images "你的原图目录" --output "本地校验结果.json"
```

静态网站直接运行 `python -m http.server 4173 --directory docs`，打开 `http://localhost:4173/`。
本地后端在 `oven-app` 目录按启动文档运行 `python -m backend.app`，默认选择新模型。如旧终端曾设置 `OVEN_MODEL`，应清除它或明确指向新权重，否则环境变量会继续覆盖默认值。

旧网页版本 `C_real_20261105` 的 ONNX/配置保留在 Git 历史（例如提交 `54b5d0e`）；旧本地权重没有删除。回滚应同时恢复 ONNX 和 model.json，避免类别/输入配置不匹配。团队模型归档目录未改写。

## 模型局限

检查点 adaptation 元数据标注：只训练最终分类线性层，使用固定最终轮次；`independent_test=false`。本轮训练列出了 12 类，“整鸡”“可颂”未参与本轮训练，但仍在输出类别中。因此本次替换不代表已证明这两类或所有烤箱实拍的准确率提升。应继续用独立原图和 USB 摄像头画面验证；最高候选分数并不等同准确率，网页保留人工确认。
