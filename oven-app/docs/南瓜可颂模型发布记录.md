# 南瓜可颂补充模型：网站发布记录

网站和本地 Flask 默认推理权重统一更新为 `model_C_pumpkin_croissant.pt`，网页显示“十四类南瓜可颂补充版”，版本 `C_pumpkin_croissant_9db30ce0`。模型权重与本地对比版完全相同，仅移除显示名称和版本号中的“对比”标记。

## 来源和输入约定

- 模型来源：用户提供的《十四类食材识别_南瓜可颂补充_代码与权重.zip》。模型训练由组员完成，本次提交负责网站接入、验证与发布。
- 原始 PT SHA256：`9db30ce0eedee1fe8d53843eaff34d3b49e435c3f2222417ce79db21584c674a`。
- 网页 ONNX SHA256：`366c38043e1c4d520d734f949dae64832cce085778204726737796a7d1bd2156`。
- MobileNetV3-Small，224×224 RGB/NCHW，按比例双线性缩图、白底补边、权重中的 mean/std，输出 logits 后 softmax。
- 14 类顺序严格来自检查点：南瓜、吐司、牛排、玉米、西兰花、鸡翅、芦笋、培根、三文鱼、整鸡、土豆、香肠、薯条、可颂。
- 使用此前修复的 Pillow 一致性预处理；图片上传、USB 摄像头和人工确认交互继续使用。模型 URL 含哈希参数，刷新后按新 model.json 加载相应权重。

## 验证

- 对比版、发布版 ONNX 字节一致，原始 PT 字节一致。
- 导出随机张量的 PyTorch/ONNX 最大 logits 绝对差 `3.941357135772705e-06`。
- 15 张现有图片最高候选一致 15/15，最大 logits 绝对差 `4.863739013671875e-05`，满足 rtol/atol 各 1e-4。见[转换校验](南瓜可颂模型转换校验.json)。这是一致性抽查，包含重复图片，没有独立真值标签，不作为准确率评测。
- 新默认权重下 4 项 Python 真实接口测试通过；25 项 Node 模型、预处理和摄像头测试通过。
- 本地静态资源和模型通过 HTTP 完整性校验。此前自动浏览器连接超时，未完成自动上传界面实测；本次沿用用户认可的同一份本地对比模型。
- 原模型包说明的评测属于开发对照，南瓜评测与训练同来源、整鸡缺评测；置信度不代表准确率，网页继续人工确认。

## 复现

在仓库根目录、项目依赖环境中设置 `PYTHONPATH=oven-app;oven-app/src`：

```powershell
python oven-app/reproduce/export_web.py --model oven-app/models/model_C_pumpkin_croissant.pt --output docs --id C_pumpkin_croissant --name "十四类南瓜可颂补充版" --version C_pumpkin_croissant_9db30ce0
python oven-app/reproduce/verify_web_export.py --model oven-app/models/model_C_pumpkin_croissant.pt --web-dir docs --images "你的原图目录"
```

默认后端也使用该 PT。曾设置 OVEN_MODEL 的终端仍会优先使用该变量，需清除或指定新权重。
