## 浏览器端识别

GitHub Pages不能运行原来的Python后端。这次在Codex协助下，把分类模型转换成ONNX格式，改为在浏览器里完成识别。

- 保留十四类食材、前三候选、预测置信度和人工确认流程。
- 保留“以上都不是”和“识别下一张”按钮。
- 图片只在当前浏览器中处理，不上传服务器。
- 使用固定版本的ONNX Runtime Web 1.22.0。首次使用需要下载模型和运行库。

## 发布目录

我把公开站点文件放在仓库根目录docs中，里面只有网页、脚本、类别配置、ONNX模型和.nojekyll。工作日志等文档仍放在oven-app/docs，训练图片没有放入站点目录。浏览器端运行需要下载模型，因此发布用ONNX模型也会公开。
