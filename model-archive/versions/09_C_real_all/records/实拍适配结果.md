# 十四类食材识别实拍适配

从C v2继续训练20轮，最佳第6轮。推理仍采用十四类MobileNetV3-Small。
本次仅训练食材分类，实际训练使用全部1428张实拍与每旧类60张共840张回放图。
整鸡和南瓜缺少实拍，本轮仅靠各60张旧训练图片维持其识别。
父模型C v2和适配版用于真实场景改进，不能将本轮结果单独解释为初类到最终模型的增量效果。

## 数据和限制

检查了12类各命名序列的首中末代表帧，未逐张视觉复核全部1428张。原图全部成功解码且有元数据指纹的均匹配。按用户要求全部使用，包括上一版暂缓的一张有手部遮挡玉米图。少量手部、工具及锡纸反光仍可能影响表现。
按文件夹和代表图确认食材标签，忽略采集JSON里沿用的候选pumpkin类别。可颂本批为熟制外观，牛排本批主要有锡纸，采样覆盖仍有限。原始JSON和图片保持原文件。
固定配置为AdamW、头学习率0.00005、骨干学习率为头的20%、余弦调度、gentle_retention增强、目标域抽样占比60%、批量16、CPU4线程。未开展新的类别增量。
权重保存、独立进程加载、类别顺序、网络形状、有限数值、1428张原图与副本指纹和24张输入一致性检查通过。

## 与上一版比较

上一版521张实拍训练版本，在相同1428张实拍上的训练关联诊断为1300/1428（91.04%），旧验证为398/407（97.79%）。
本版和上一版起点及主要超参数相同，均训练20轮。样本量增加也增加了每轮更新次数。
已记录实际抽样次数，全部1428张实拍均在训练中被读取，未只进入清单。

本轮选中的第6轮权重在同一批实拍上比上一版少20张正确，回代89.64%，上一版91.04%。两版旧网图验证均398/407。可颂由98/110变为105/110，鸡翅由96/129变为90/129，香肠由61/97变为57/97。整体表现存在取舍，两个版本分别保留供后续独立实拍验证。
