# 十四类食材识别固定机位增强优化

采用oven_real光照增强和0.05训练标签平滑，固定机位小目标保持原尺寸。旧增强行为及旧配置默认值保留。73项相关检查通过。
安装Python依赖后在此目录执行 pip install -e .。
预测命令为 python predict.py --model models/model_C_real.pt --image 实拍图片.jpg。
输出十四类之一及已知类别相对分数，仅识别食材。南瓜和整鸡仍保留在类别中，原训练批缺这两类实拍，南瓜新增图片仅作验证和测试。
本批1428张实拍全部用于训练，回代成绩用于检查拟合，实际泛化需要新的独立拍摄验证。
详细结果见records/实拍适配结果.md。配置和清单含开发机原始路径，复训前需准备数据和修改路径副本。
