# 十四类食材识别实拍适配

从与上一轮相同的全量适配起点训练15轮，最佳第14轮。推理仍采用十四类MobileNetV3-Small。
本次仅训练食材分类，实际训练使用全部1428张实拍与每旧类60张共840张回放图。
整鸡和南瓜缺少实拍，本轮仅靠各60张旧训练图片维持其识别。
父模型全量适配版和再训练版用于真实场景改进，不能将本轮结果单独解释为初类到最终模型的增量效果。

## 数据和限制

检查了12类各命名序列的首中末代表帧，未逐张视觉复核全部1428张。原图全部成功解码且有元数据指纹的均匹配。按用户要求全部使用，包括上一版暂缓的一张有手部遮挡玉米图。少量手部、工具及锡纸反光仍可能影响表现。
按文件夹和代表图确认食材标签，忽略采集JSON里沿用的候选pumpkin类别。可颂本批为熟制外观，牛排本批主要有锡纸，采样覆盖仍有限。原始JSON和图片保持原文件。
固定配置为AdamW、头学习率0.0001、骨干学习率为头的30%、余弦调度、oven_real固定机位光照增强和0.05标签平滑、训练图片逐轮完整打乱遍历、批量32、CPU4线程。未开展新的类别增量。
权重保存、独立进程加载、类别顺序、网络形状、有限数值、1428张原图与副本指纹和24张输入一致性检查通过。

## 本轮代码与增强优化

新增oven_real固定机位增强，保留整幅画面和小目标尺寸，改变曝光、平滑侧光、gamma及小范围色温，恢复缓存图片的纯白整行/列。旧增强保持原行为。
标签平滑只用于训练交叉熵，取0.05，旧配置默认0。训练损失定义因此改变，不能将本轮训练损失直接与旧轮比较；验证交叉熵仍不使用平滑。
与上一轮相同数据、父权重、种子、15轮及学习率，对比的是增强和标签平滑的联合修改，没有单因素消融。
73项相关测试通过，覆盖小目标位置/尺寸、补边、确定性、旧配置兼容及真实微型训练的损失接线。
上一轮基线验证161/214（75.23%），复用测试153/213（71.83%），旧网图验证395/407（97.05%）。
食材类别仍为十四类，模型结构与参数形状未增加。
