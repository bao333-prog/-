# 第一次增量：十类模型B

本包包含六类父模型A及第一次增量后的十类B，网络为MobileNetV3-Small分类，不支持检测或计数。
旧类别顺序原样保留，末尾依次追加芦笋、培根、三文鱼、整鸡。

本轮从正式A加载参数后扩层，旧六行权重原样复制，新四行随机初始化，再继续训练。
每旧类20张训练图回放（共120），加550张新类训练图；验证275张；固定测试277张。
训练20轮，学习率0.0001，CPU四线程，batch16；温和增强、补边、训练类别加权。
最佳第7轮，按验证准确率、同分验证损失选择。

固定网页测试：
- 旧六类：153/159，96.23%。
- 新四类：117/118，99.15%。
- 十类总体：270/277，97.47%。
- 旧类相对A下降3.14个百分点，负数表示提高。

旧类下降超过2个百分点，本轮未达到原定旧类保持目标；鸡翅仅8/12，需重点关注。

## 使用

需要Python3.10或更新版本。在解压根目录执行：

    python -m pip install -e .
    python predict.py --model models/model_B.pt --image "你的图片.jpg"

src/oven_food/包含中文注释的模型扩层、训练、回放和评测代码。
predict.py共用训练输入处理函数，自动按权重的类别顺序、补边方式和归一化约定预测。
models/parent_A.pt是父模型，只识别旧六类；models/model_B.pt识别十类。

## 审计与复现

records/内有固定划分、筛选理由、来源分组、实际训练清单、逐张测试、混淆矩阵、训练记录与父模型SHA。
reproduce/内有本次数据准备、运行和验证脚本；它们依赖原电脑路径，供查阅。
tests/内有增量回归检查，验证扩层保留旧参数、类别下标和回放隔离等。
本包不含原图或224×224准备副本。其他电脑复现训练需另取完整数据及相同划分，调整数据路径。
训练配置的checkpoint路径也需要改为包内父模型位置。

## 边界

这是样本回放类增量，没有蒸馏/参数隔离对照，不代表算法最优。验证/测试图片不用于回放。
旧类在完整十类输出中评测，没有截取六类输出人为抬高成绩。
三文鱼70张缺来源记录，全部转载及同源关系未逐站核实，仍可能遗漏近重复。
网图分数不是烤箱或RK3506部署结果。不支持未知食材拒识；其他食品也会被归入十类之一。
本次没有根据测试结果追加调参，没有开始第二次增量。
