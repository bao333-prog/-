# 十四类增量训练框架改进

用户要求优化模型框架并做适度数据增强。按现有项目目标，重点为旧类保持，继续兼容CPU和后续端侧推理。

保留MobileNetV3-Small和14类推理输出，不增加推理网络层。采用冻结的十类B教师，只对旧类训练样本蒸馏，教师预测错误的样本仍做监督训练但不蒸馏。学生的蒸馏概率在全部14个输出上归一化，教师新四类概率视为零，以避免仅截取旧类后无法约束新类抢占概率的问题。

训练损失为监督交叉熵加1.0倍旧类蒸馏KL，温度2并乘T²。教师只在训练时使用，不参与优化器、不保存进部署权重，保持eval，不更新BN或梯度。

分组学习率：骨干为分类头的0.2倍；分类头初始0.0001，余弦下降至初始的5%。训练20轮，CPU四线程、batch16，种子42，AdamW、类别加权。新配置默认关闭这些功能，旧配置行为保持。

增强新增gentle_retention：完整主体补边，50%镜像、±6°旋转、亮度/对比度/饱和度0.92～1.08，90%～100%缩小并平移；低概率轻微色温、gamma、传感噪声和高质量JPEG。不进一步模糊或降低分辨率，不裁切或遮挡主体。

从与原C相同的鸡翅补强B重新做第二次增量：每旧类20张回放、全部529张新类训练图、相同407张验证，四类追加顺序不变。冻结旧数据筛选、来源分组和所有测试集合，不新增图片或将增强图计为独立数据。

只用验证集比较原C和改进候选；本轮不重新评分已公开的409张测试，不能据验证分数宣布原测试保持目标通过。保留所有旧模型与代码包，不自动替换正式版本。不做逐项消融，不将联合改变的收益归因于某一项。

备选考虑：加大回放有更多旧样本但改变记忆预算；更大骨干会增加推理成本。本次先保持架构和回放预算，改进训练约束及增强。

技术依据：[蒸馏原论文](https://arxiv.org/abs/1503.02531)、[PyTorch KLDivLoss](https://docs.pytorch.org/docs/stable/generated/torch.nn.KLDivLoss.html)。仅对旧样本蒸馏和全输出归一化是本项目的具体设计，不声称实现了某一完整既有增量算法。
