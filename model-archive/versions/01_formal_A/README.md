# 正式六类基础模型A：网图版本

模型为MobileNetV3-Small单标签分类，不是YOLO，不支持计数。
数据版本：formal_A_20261025_113459。输入1090张，暂排除45张；训练729、验证157、测试159。
训练20轮，学习率0.0003，全模型更新。按验证准确率选第1轮；同分保留最早轮次。
固定网页测试：158/159，99.37%。
此分数不等于真实烤箱或RK3506验收。来源信息不完整，未保证所有同源转载已识别。

## 文件

- models/model_A.pt：正式A权重，含类别顺序、数据版本和预处理约定。
- src/oven_food/：项目完整Python包，模型、训练、数据读取及评测代码含中文注释。
- predict.py：有中文注释的原图预测示例，自动执行与训练一致的缩放补边及归一化。
- records/：本轮报告、逐轮记录、评测结果、固定清单、来源分组及排除理由。
- reproduce/：本次使用的数据准备、训练运行与验证脚本，用于查阅；脚本及records中的路径为原电脑路径。

## 在其他电脑预测

需要Python3.10或更新版本。解压后在此目录执行：

    python -m pip install -e .
    python predict.py --model models/model_A.pt --image "你的图片.jpg"

本包已经包含训练权重，预测不需要重新下载官方预训练模型。
程序输出预测类别和六类分数。类别顺序以权重文件为准，不要自行按文件夹顺序解释。
这是六类封闭分类器：其他食材也会被归入六类之一，分数不是准确率或可靠性保证。

## 重复训练或开展增量

本包不含1090张原图或1045张训练副本。records中的清单是原电脑固定划分记录，
不是可在任意电脑直接运行的数据路径。复现训练需另取完整数据，按记录准备副本，
调整train_config.json中的manifest、data_root、output_dir，再运行项目训练入口。
不得重新随机划分后把成绩与本轮当成同一项实验比较。

训练前已有官方预训练缓存。本轮从该预训练起点训练，没有沿用小样本试跑权重。
之后可从models/model_A.pt开展正式增量，但现有train.py只支持固定类别训练/同类别续训，
并未实现新增类别的分类层扩展、回放或蒸馏；不能直接拿新增类别数据作为普通续训输入。
后续增量应另外实现并验证扩类流程，同时保留本次旧类测试清单。

## 数据与输入约定

原图只读。处理顺序：EXIF方向校正、透明像素合成白底、等比例缩放和白底补边到224×224、
像素除255、ImageNet均值[0.485,0.456,0.406]及标准差[0.229,0.224,0.225]归一化。
原来的baseline会中心裁剪；本轮先准备正方形副本，因此没有在训练时丢失主体。
predict.py已实现原图端一致的处理，请不要只调用旧baseline去直接裁剪原图。

模型代码复用官方torchvision结构，只替换最后分类层。中文注释解释了预训练、分类层、
标签顺序、训练/验证隔离、梯度更新、最佳模型保存及预测预处理。
