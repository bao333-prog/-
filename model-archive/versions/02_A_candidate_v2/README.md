# 六类模型A候选v2

在既有MobileNetV3-Small上改进构建与训练，不更换为检测模型，不支持计数。
旧A权重与数据划分保留。候选从官方预训练权重重新训练，没有加载旧A。
训练20轮、学习率0.0003、CPU四线程、batch=16。新增配置：

    "augmentation": "gentle",
    "resize_mode": "letterbox",
    "class_balanced_loss": true

温和增强只用于训练；类别加权仅按训练集计算。验证准确率同分时按较低验证损失选择。
候选最佳第9轮；验证准确率100.00%，验证损失0.001206。
没有重新评测已公开的旧测试集，不能把旧A的99.37%成绩写在候选v2名下。

## 使用

需要Python3.10或更新版本。解压后运行：

    python -m pip install -e .
    python predict.py --model models/A_candidate_v2.pt --image "你的图片.jpg"

src/oven_food/内有中文注释。predict.py共用项目的输入处理函数，按权重元数据执行补边、
透明合成白底、EXIF方向校正和归一化。旧权重没有新元数据时，仍按旧默认或旧A约定解释。

models/：候选v2权重，不含旧A权重。
records/：训练配置、验证结果、验证集扰动诊断、逐轮记录与真实训练运行日志。
tests/：本次回归检查，含真实小数据训练到加载评测的集成检查。
reproduce/：本次训练与验证脚本，依赖原电脑固定数据目录，仅供查阅。

本包不含食材图片。records内的训练配置使用原电脑数据清单绝对路径；异机复现须另取数据并
改正数据路径，保持原有划分不变。预测使用包内权重不需要下载官方预训练模型。

## 结果边界

模型结构相同，训练增强不会增加推理网络复杂度。代码正确性检查与验证集诊断不等于真实泛化
已经改善，仍需新的独立样本验证。来源不完整、近重复遗漏、类别外观范围不足不能靠代码消除。
当前仍是六类封闭分类，不支持未知食品拒识。后续扩类、回放和蒸馏尚未实现。
