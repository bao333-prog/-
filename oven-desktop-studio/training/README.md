# 训练与升级

本流程用项目十四类 C v2 的原训练模块继续训练食材分类，层位和锡纸标签保留在来源清单中。当前训练输出仍为食材分类。

1. 在源码目录执行 `training/Setup.ps1 -Python 你的Python路径`，安装独立训练环境。
2. 在桌面程序导出已确认训练素材。按拍摄批次制作 JSON，例如 `{"鸡翅批次1":"train","鸡翅批次2":"val"}`。同批次照片全部放在同一集合。验证批次用于选模和对比，报告属于验证成绩。
3. 点击“训练与升级”，依次选择素材 ZIP、批次 JSON、起点 .pt 权重、输出父目录。默认训练 5 轮，CPU、学习率 0.0001、冻结特征提取层，使用原工程的 gentle 增强。训练各类样本覆盖情况影响遗忘风险，建议带入各旧类训练素材。
4. 进度窗口显示日志。完成后打开输出文件夹，查看 comparison.json 的新旧整体及逐类成绩。
5. 从“模型管理”导入 model-package.zip，试运行后选择启用。可以切回原版本。

运行脚本也可用 `--epochs` 调整轮数。输出目录必须是新目录，保存训练起点哈希、来源标签、数据划分、训练记录、best.pt、ONNX 和对比报告。重复照片按文件哈希去重，跨集合重复或标签冲突会报错。未填写拍摄批次需先补齐，未知食材类别需先在原工程进行扩类。

源码来源为用户提供的 https://github.com/bao333-prog/- 仓库 main 分支下 model-archive/versions/07_C_retention_v2/src/oven_food，下载于 2026-11-17。起点权重来自同版本 models/model_C_v2.pt。它与当前 EXE 内置模型的训练来源关系尚未核实，界面明确要求选择训练起点。

已安装独立训练环境，版本记录在 requirements-validated.txt。2026-11-17 使用四张明确标记的合成图跑通一轮训练、新旧验证对比、ONNX 导出及数值一致性检查。真实样本训练与识别效果提升仍待验证，合成图结果不能作为食材准确率。

## 一键训练更新
“训练与升级 → 一键训练并更新”首次选择素材 ZIP、批次划分、起点权重和输出位置，后续复用这些路径。训练完成后自动试运行模型包、导入并启用，关闭训练窗口后主界面重新加载新模型。旧模型保留在模型管理。可用“重新选择训练材料”更换路径。
一键更新读取所选文件的当前内容，新增实拍需先重新导出素材到同一路径。每次仍从所选 .pt 起点训练，不自动把起点改成上一轮产物。自动检查验证模型能否运行，识别效果请查看 comparison.json。

自动导入数据集：选择总文件夹，第一层子目录为食材标签。按每类拍摄组约80/20划分；食材目录下的下一层子目录视为拍摄组，平铺照片按内容哈希作为组。同文件去重，跨标签重复报错。缺少拍摄组时提示潜在连拍泄漏。导入后自动保存训练设置，默认起点归档 C v2。导入后的素材包是当前文件夹快照，新增照片后需重新导入。
